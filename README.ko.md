# 한국전자계약 · e-Contract (데모)

빌드가 필요 없는 **브라우저 전용 전자계약/전자서명 데모 앱**입니다.
템플릿을 고르고, 마법사로 항목을 채우고, 미리보기를 확인한 뒤,
**캔버스에 서명을 그려 날인**하고, Web Crypto API로 계산한
**실제 SHA-256 문서 해시**로 위·변조 여부를 확인합니다. 모든 데이터는
사용자의 브라우저에만 저장됩니다.

**English: [README.md](README.md)**

## 🔗 라이브 데모
**https://clsoftlab-lang.github.io/e-contract-app/**

## 주요 기능
- **템플릿 갤러리** — 근로계약, 부동산 임대차, 금전 차용, 용역/프리랜서, 비밀유지(NDA) 5종.
- **작성 마법사** — 당사자/조건/금액 그룹 필드, 필수값 검증, 템플릿별 체크리스트.
- **실시간 미리보기** — 입력값으로 조항 자동 완성, 빈 값은 눈에 보이는 공란으로 표시.
- **캔버스 서명** — 마우스·터치(pointer 이벤트, 고해상도) 지원, 지우고 다시 서명, 서명 시각·서명자 이름 기록.
- **문서 무결성(SHA-256)** — 계약 본문의 표준 텍스트를 `crypto.subtle.digest`로 실제 해싱. 한 글자만 바뀌어도 해시가 완전히 달라집니다.
- **진행 상태** — 작성중 / 서명대기 / 완료 (서명 수로 자동 판정).
- **내 계약함** — 검색 + 상태 필터.
- **감사 로그** — 생성/서명/저장/공유 시각과 행위자 기록.
- **모의 공유 링크 + 인쇄/PDF** — `window.print()` 출력, 데모용 공유 URL(실제 전송 없음).
- **부가 기능** — 계약 항목 체크리스트, **만료 알림**(D-30/만료 태그), 카드에 SHA-256 해시 표시.
- 반응형(모바일 우선), 라이트/다크(`prefers-color-scheme`), 초기화 버튼.

## 🤖 AI 기능 (API 연동)

3가지 AI 기능이 내장되어 있습니다. **라이브 데모에서는 내장 목업(오프라인)으로 즉시
동작**하며(키·네트워크·비용 불필요), 운영자가 레퍼런스 프록시를 배포하면 실제 Claude로
전환됩니다.

1. **조항 쉬운 설명 + 리스크 플래그** — 계약 조항을 쉬운 한국어로 풀어 설명하고 위험·불리 문구(지연손해금·해지·연체 등)를 표시합니다. *(미리보기 화면)*
2. **조건 입력 → 계약 초안 생성** — 당사자·금액·기간 등 핵심 조건을 적으면 항목 값을 만들어 **마법사를 자동으로 채웁니다**. *(작성 마법사 화면)*
3. **계약 Q&A 챗봇** — 현재 계약서의 항목·조항을 근거로 질문에 답합니다. *(미리보기 화면)*

> ⚠️ **법률 자문이 아닙니다.** AI 출력은 이해를 돕는 일반 정보일 뿐이며 법률 자문이
> 아니고 틀릴 수 있습니다. 중요한 결정은 반드시 전문가의 검토를 받으세요.

**연동 방식(보안 설계):**
- `ai/config.js` — `AI_ENDPOINT` 기본값은 `""` ⇒ 오프라인 **목업**이 동작합니다. GitHub Pages 데모가 이 방식으로 돌아갑니다.
- `ai/ai.js` — `askAI(task, payload, {onToken})`: 엔드포인트가 비면 로컬 목업, 값이 있으면 프록시에서 스트리밍합니다.
- **실제 AI 활성화**: `server/`(레퍼런스 프록시)를 `ANTHROPIC_API_KEY`와 함께 배포(비용 우선 기본 모델 `claude-haiku-4-5`, `AI_MODEL`로 변경 가능, 프롬프트 캐싱, 스트리밍)한 뒤 `AI_ENDPOINT`를 그 `/api/ai` 주소로 설정하세요. [`server/README.md`](server/README.md) 참고.

> 🔐 **API 키는 오직 서버에만 두며, 브라우저나 저장소에는 절대 두지 않습니다.**
> 브라우저는 오직 여러분의 프록시 주소하고만 통신하고, 키는 프록시에만 존재합니다.
> `check.mjs`가 저장소에 키 토큰이 커밋되지 않았음을 검증합니다.

## ⚙️ 고도화 — 무인·저비용 실 AI 연동

AI 계층은 **실제 Claude**를 쓰면서도 **무인**으로 돌아가고 **비용이 저렴하도록** 튜닝되어 있습니다.

- **비용 우선 모델.** 기본값은 **`claude-haiku-4-5`**(**$1 / $5 per MTok**, 입력/출력)입니다. 품질을 높이려면 `AI_MODEL`을 `claude-sonnet-5` 또는 `claude-opus-5`로 올리세요(비용 증가).
- **프롬프트 캐싱.** 작업별 고정 시스템 프롬프트를 `cache_control: ephemeral` 블록으로 보내, 반복 호출 시 캐시를 읽어 비용을 낮춥니다.
- **출력 상한 + 예산.** 작업별 `max_tokens`를 작게(~700), IP당 요청 제한(분당 20회), 월 토큰 예산(`AI_MONTHLY_TOKEN_CAP`, 기본 2,000,000)을 둡니다. 예산 초과 시 `429 {fallback:true}`.
- **대략적 비용.** Haiku 4.5 + 캐싱 + ~700 토큰 상한이면 요청당 1센트 미만, 대략 **1,000요청당 ~$2–4** 수준입니다(입력 길이에 따라 변동, 캐싱으로 더 내려감).
- **무료 원-디플로이(Cloudflare Workers).** `server/worker.js` + `server/wrangler.toml`로 동일한 프록시를 Workers 무료 티어에 배포합니다 — **관리할 서버가 없습니다**. 키는 `wrangler secret put ANTHROPIC_API_KEY`로 한 번만 등록합니다.
- **무인 목업 폴백.** 엔드포인트가 닿지 않거나, 요청 제한·예산 초과이면 `ai/ai.js`가 오프라인 목업으로 자동 전환되어 앱이 **절대 멈추지 않습니다**. 또한 미리보기를 열면 계약서 조항을 근거로 **계약 리스크 점검 요약**(쉬운 말, 법률 자문 아님)이 자동 생성되며, 오프라인 목업으로도 완전히 동작합니다.

> 🔐 **API 키는 오직 서버에만 두며, 브라우저나 저장소에는 절대 두지 않습니다.**

## 로컬 실행
빌드도, 의존성도 없습니다. 폴더를 정적으로 서빙하세요.

```bash
python -m http.server 8981
# 브라우저에서 http://localhost:8981 열기
```

(ES 모듈과 `data/templates.json`의 `fetch()` 때문에 정적 서버가 필요합니다.)

## ⚠️ 데모 모드 한계 (반드시 읽어주세요)
- **법적 효력이 있는 전자서명 서비스가 아닙니다.** 템플릿과 조항은 일반적인 데모 샘플이며 법률 자문이 아닙니다.
- **서명·해시는 전부 클라이언트(브라우저)에서만** 처리됩니다. 그려진 서명 + SHA-256 해시는 무결성 시연일 뿐, 공인 전자서명이 아닙니다.
- **localStorage는 실제 데이터베이스가 아닙니다.** 이 브라우저에만 저장되며 백업되지 않고 언제든 삭제될 수 있습니다.
- **실 계정·개인정보·본인인증이 없습니다.** 반드시 가상의 데모 데이터만 사용하고, 실제 개인정보를 입력하지 마세요.
- **실제 서비스로 만들려면** 백엔드/서버, 공인 전자서명·PKI, 본인인증, 안전한 저장소, 법률 검토가 필요합니다.

## 기술
순수 HTML + CSS + ES 모듈 자바스크립트. 서명은 `<canvas>`,
SHA-256은 `crypto.subtle`(Web Crypto), 저장은 `localStorage`, 출력은
`window.print()`. 상대 경로만 사용하여 별도 빌드 없이 GitHub Pages에 배포됩니다.
